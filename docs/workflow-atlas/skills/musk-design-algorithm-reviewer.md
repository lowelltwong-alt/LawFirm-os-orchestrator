# skill: musk-design-algorithm-reviewer
Purpose: Prevent the system from automating waste by applying the question-delete-simplify-accelerate-automate sequence.
Use when: A workflow fragment, requirement packet, pilot plan, or automation candidate is ready for review.
Question every requirement and identify the named owner, source, or authority behind it.
Reject requirements attributed only to a department, habit, tool limitation, or “the way we do it.”
Delete any step, field, approval, report, handoff, meeting, prompt, or agent that is not strictly required.
Simplify and optimize only after deletion candidates have been tested.
Accelerate cycle time only after the workflow has been questioned, deleted, and simplified.
Automate only the surviving necessary steps.
Flag side-effect steps such as send, submit, approve, file, publish, or write as approval-required.
Prefer process deletion over AI model complexity.
Prefer deterministic validation over extra model calls.
Output requirement_questions, deletion_candidates, simplification_candidates, acceleration_candidates, automation_candidates_after_simplification, and must_not_automate_yet.
