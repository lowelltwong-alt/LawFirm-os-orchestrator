# Stop Conditions

Stop immediately if any of these occur:

- The working tree is dirty before starting.
- Codex needs to edit Substrate or Exception Lake for a seed-only pass.
- Implementation requires live web crawling.
- Implementation requires model calls.
- Implementation requires external APIs.
- Implementation requires scheduled jobs.
- Implementation requires external writes.
- Implementation would make optimizer outputs authoritative.
- Implementation would restore green authority automatically.
- Implementation would let compute ROI override RYG.
- Implementation would let game theory override RYG.
- Implementation would mutate canon.
- Tests fail.
- Safety check fails.
- Evals regress.
